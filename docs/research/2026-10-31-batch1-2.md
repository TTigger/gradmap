# 研究紀錄：2026-10-31（第一、二批）

記錄查了什麼、怎麼查、哪裡卡住。結論已經整理進 `data/` 和 `docs/verification/`。

## 第一批：台師大、中央、中興、政大（完成）

- 中央、中興：簡章 PDF 直接下載，用 `mutool` 逐頁抽文字。
- 台師大：使用者給的網址 `/xhr/announcements/file/...` 打開是 PDF.js 閱讀器的外殼頁，看起來像要密碼；實際檔案在 `/uploads/bulletin_file/file/...`，沒有加密。
- 政大：使用者沒給網址；從 WebSearch 找到公告頁 → 頁面中的下載連結。
- 表格欄位錯位的頁面（政大、中興考試時間表、台師大放榜一覽表），改用 `mutool draw` 轉成 PNG 人工核對。**台師大資工的放榜日就是在這一步發現是 3/18，不是 2/25。**

## 第二批：其餘 10 校（部分完成）

- **台聯大碩士班聯招（116）**：只含化學、物理、電機、文化研究類，**不含資工**。簡章摘要存在 `sources/116/ust.pdf`。所以四校資工所都是各校自行招生。
- **台大**：116 未公告。115 簡章按系所分檔，從 `exam.aca.ntu.edu.tw/grab/Brochure/detail.aspx` 取得 905（資工＋AI聯招）、914（網媒所）、904（電機系資安碩士班）。**904 是 100% 書審**，依使用者要求特別標記。
- **北科大**：官方公告 116 簡章「預定 115 年 11 月中下旬公告」。
- **陽明交大**：網頁仍是 115 年度。
- **清大、成大**：招生網站用 JavaScript 載入內容，curl 抓不到；WebSearch 也找不到 PDF。
- **中山、中正、台科大、北大、海大**：WebSearch 只找到舊年度或甄試資料。

## 工具與環境

- `scripts/pagetext.py`：抓網頁文字和連結。一開始用 Python urllib，但台大網站的憑證在 Python 3.14 驗證失敗；改成呼叫 curl（照常驗證憑證）。曾經試過關閉憑證驗證，被安全檢查擋下，之後不再使用這種做法。
- WebSearch 對台灣學校的簡章 PDF 收錄很差，比較有效的是直接連各校招生網站。
