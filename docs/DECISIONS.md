# 決策紀錄

規則性的決定都寫在這裡，之後遇到同類問題照這份處理。

| 日期 | 決定 | 理由 |
|---|---|---|
| 2026-10-31 | 只收考試入學，不收推甄 | 使用者範圍 |
| 2026-10-31 | 「資工所」依實際內容判斷，不看名稱（例：政大資訊工程學系原名資訊科學系） | 各校命名不同 |
| 2026-10-31 | 近親所也收，標 `kind: near_kin`，網站可隱藏（例：台大網媒所、政大資安學程） | 考科接近，可能順便報 |
| 2026-10-31 | 全部書審、不考筆試的系所，標 `review_only: true` 並在網站醒目標示 | 使用者要求 |
| 2026-10-31 | 使用者提供的資料一律視為線索，必須對照官方簡章 | 使用者要求 |
| 2026-10-31 | 頁碼寫「PDF 頁 / 印刷頁」，例：`p42 / 38` | 兩種頁碼常不同 |
| 2026-10-31 | 表格容易錯位的頁面，轉成圖片人工核對 | 抽文字時欄位會亂掉（台師大放榜日就是這樣抓到的） |
| 2026-10-31 | 116 未公告的學校，可用前一年資料當參考，但必須標 `status: pending` 和 `year` | 讓網站先有內容，又不會誤導 |
| 2026-10-31 | 簡章 PDF 只放本機 `sources/`，不進 git；repo 存 SHA256SUMS | 檔案大、可重新下載 |
| 2026-10-31 | 所有專案檔案（含下載資料、暫存）都放 `~/Projects/gradmap/` 內 | 使用者要求 |
| 2026-11-01 | 歷年數據只把官方統計（grade A）當正式數字；新聞數字可列入但標 grade B 並寫明「非官方」 | 避免把媒體轉述當成官方資料 |
| 2026-11-01 | 錄取率＝正取人數 ÷ 報名人數（不含備取遞補）；各校口徑不同時在備註說明 | 統一跨校比較的定義 |
| 2026-11-01 | 搜尋摘要裡看到的數字，沒開原始檔核對就不採用（例：中央 115 資工類 2,134） | 摘要可能斷章取義 |
| 2026-11-01 | 網站擋程式下載時，不偽裝瀏覽器繞過，改用瀏覽器或記為「需要人工處理」 | 尊重網站設定 |
| 2026-11-01 | 備考情報（心得、補習班、媒體）放獨立分頁，標來源等級，不影響其他分頁的官方資料 | 使用者要求 |
| 2026-11-01 | 每週查核在獨立分支 `check/<日期>` 進行，只產生報告和修改，不動 main、不 push | 使用者審核後再採納 |
| 2026-11-01 | 歷年數據分成 `published`（給使用者看）與 `todo`（排程內部待辦）；registry 的 `watch`、history 的 `todo` 建置時移除，不進網站 | 內部操作細節會讓使用者誤會 |
| 2026-11-01 | 簡章更正記在 `data/schools/<id>.yaml` 的 `changes`；網站標出 45 天內的變動，比使用者上次來訪新的標「新」 | 讓使用者一眼看到哪裡改了 |
| 2026-11-01 | 「我的志願」只存在使用者瀏覽器（localStorage）；下載 .ics 在瀏覽器端產生，另外每校各有一個可訂閱的 .ics | 不需要帳號或伺服器 |
| 2026-11-01 | 新增 `scripts/verify-src.mjs`：自動核對日期、名額、比例是否出現在標註的簡章頁；個位數名額仍需人工看 | 降低抄錯頁碼或數字的風險 |
| 2026-11-01 | 台師大 AI 跨域應用研究所、陽明交大智能系統研究所列為近親所並標「只書審」 | 兩所都不考筆試（書審／口試），但與資工高度相關；和台大資安碩士班（904）一致處理，可用「顯示近親所」隱藏 |
| 2026-11-01 | 不做「報考流程打勾清單」 | 網站定位是公開資料平台；個人狀態只能存瀏覽器，換裝置會不見。改用 .ics 提醒＋志願清單分享連結 |
| 2026-11-01 | 伺服器憑證鏈不完整時，下載 CA 官方中繼憑證、與系統根憑證合併後用 `--cacert` 驗證 | 不關閉 TLS 驗證也能取得檔案（陽明交大） |
| 2026-11-01 | 考古題索引只標我們在官方頁面上親眼看到的年度；看不到的標「?」 | 避免把搜尋摘要當事實 |
