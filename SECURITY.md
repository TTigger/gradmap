# Security Policy

GradMap is a static website (no accounts, no server-side code, no personal data collected).

**Reporting a vulnerability:** please use GitHub's private vulnerability reporting
(Security tab → "Report a vulnerability"). Do not open a public issue for security problems.

**Wrong data** (dates, quotas, subjects) is not a security issue — please open a normal issue
with the official source URL and page number.

---
資安問題請用 GitHub 的私下回報功能（Security → Report a vulnerability），不要開公開 issue。
資料錯誤（日期、名額、考科）請開一般 issue，並附官方來源網址與頁碼。
